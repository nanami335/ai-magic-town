《流光鎮物語：AI 魔法見習師》第一版

檔案說明：
- index.html      遊戲主程式
- manifest.json   PWA 設定
- icon.svg        圖示
- sw.js           離線快取 service worker

如何公開分享：
1. 把整個 ai_magic_game 資料夾上傳到 GitHub repository。
2. 到 Settings → Pages，選擇 Deploy from branch。
3. Branch 選 main / root。
4. 幾分鐘後即可得到公開網址。

也可用 Netlify / Cloudflare Pages 直接拖曳整個資料夾部署。

手機遊玩方式：
- 用手機瀏覽器開啟網址即可玩。
- 可以加到主畫面，像 App 一樣啟動。

這一版包含：
- 城鎮探索
- 三個學派修行任務
- 一個特殊任務（招募隊友）
- 一場回合制小考 BOSS 戰
- 本機存檔
- 可公開分享
